# Reputation, Shareability and Journalist Fast Path

This layer exists to make Lorenza Volponi easier to discover, attribute, quote and contact without manufacturing reputation.

## Evidence rule

A reputation signal is publishable only when an external, auditable source exists. Mentions are not endorsements. Search position is not authority. Clicks are not leads. Leads are not clients. Nothing is promoted to a stronger evidence state without proof.

## Shareability rule

A shareable object has one canonical quote, one author, one canonical URL and ready-to-use social text. Social copies preserve attribution and do not invent context.

## Journalist mode

`/journalist-mode.json` is a machine-readable shortcut to existing source-room material: media facts, press kit, evidence, citation guidance and attributable quotes. It intentionally avoids inventing a press email or phone number that is not already verified in the repository.

## Visual boundary

This layer does not redesign the public Lorenza profile. The goal is backend density and distribution readiness around one canonical entity.
