# Authority Engine

The project now treats authority as a measurable pipeline rather than a publishing claim.

## Loop

1. Primary-source watcher detects material changes in official OpenAI surfaces.
2. Editorial review decides whether the change is factual, relevant and publishable.
3. Radar, evidence ledger, datasets, feeds and canonical pages are updated together.
4. Search and crawler health checks validate discoverability after deployment.
5. Authority Observatory validates owned citation surfaces and maintains a stable query portfolio.
6. Search Console supplies verified impressions, clicks, CTR and position. External citations/backlinks are only recorded when supported by verifiable evidence.

## Non-negotiable boundary

Detection never auto-publishes factual claims. The system may prepare evidence and a proposed editorial diff, but a human review remains the publication gate. The observatory never invents rankings, backlinks, press coverage or AI citations.

- Search Console ranking hunt — verified organic search evidence when credentials are configured.
- Radar source watch — primary-source change detection with editorial gate.
- `/intelligence.json` and `/media-facts.json` — machine-readable citation surfaces.
