# Lorenza Distribution Engine

The public visual identity stays intentionally concentrated. Distribution readiness is handled through machine-readable objects around one canonical entity.

## Goals

- Make Lorenza Volponi easy to attribute correctly.
- Give journalists a fast path to evidence, facts and quotes.
- Make social sharing preserve author + canonical URL.
- Record reputation only when external evidence exists.
- Avoid multiplying visual pages for every keyword or channel.

## Core endpoints

- `/journalist-mode.json`
- `/editorial-source.json`
- `/shareable-quotes.json`
- `/share-card-manifest.json`
- `/quote-attribution.json`
- `/reputation-signals.json`
- `/reputation-policy.json`
- `/reputation-sources.json`
- `/distribution-manifest.json`

## Non-negotiable rule

No press mention, backlink, social citation, AI citation, ranking, partnership, lead or client is published as fact without an auditable evidence source.
