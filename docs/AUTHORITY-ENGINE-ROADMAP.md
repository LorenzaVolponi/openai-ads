# Authority Engine Roadmap

## Implemented in this branch

- owned authority surface monitoring;
- deterministic citation evidence ledger;
- live verification of declared backlink/press/industry/academic/AI citation sources;
- scheduled Authority Observatory twice weekly;
- optional real Google Search Console evidence using read-only service-account credentials;
- consolidated executive report and single GitHub issue refresh;
- public `/autoridade` page;
- machine-readable `/authority.json` endpoint;
- sitemap and Intelligence Hub integration;
- zero-AI monitoring path with explicit human publication gate.

## Intentionally not automated without a trusted source

- web-wide backlink discovery;
- press discovery without a verifiable feed/search provider;
- AI-answer citation discovery without an auditable provider/API;
- causal claims from ranking movement;
- automatic factual publication.

These gaps should only be filled when a reliable evidence source can be added without weakening provenance.
