## OAI-AdsBot
Purpose: OpenAI crawler used for validation/review of web landing pages submitted as ChatGPT ads. OpenAI guidance says advertisers must allow OAI-AdsBot.
robots.txt:
User-agent: OAI-AdsBot
Allow: /
Published IP ranges: https://openai.com/adsbot.json
Official advertiser guidance: https://help.openai.com/pt-br/articles/20001243-orientacoes-para-anunciantes-sobre-como-permitir-rastreadores-da-web-da-openai

## OAI-SearchBot
Purpose: OpenAI crawler associated with public web discovery/search experiences. OpenAI advertiser guidance recommends allowing OAI-SearchBot together with OAI-AdsBot.
robots.txt:
User-agent: OAI-SearchBot
Allow: /
Published IP ranges: https://openai.com/searchbot.json
Official advertiser guidance: https://help.openai.com/pt-br/articles/20001243-orientacoes-para-anunciantes-sobre-como-permitir-rastreadores-da-web-da-openai

## Infrastructure checklist
- Return a successful HTTP response for public landing pages.
- Do not accidentally block crawlers in WAF/CDN/bot mitigation.
- Inspect 403 Forbidden and 429 Too Many Requests events.
- Avoid CAPTCHA, login gates and unsupported redirect chains on ad landing pages.
- Use official IP-range files when infrastructure requires IP allowlisting.
- Keep canonical URLs, sitemap, structured data and internal linking consistent.
