# Security Policy

This repository powers the independent editorial and research property at `https://openai-ads.volponi.tech`.

## Scope

Security reports are welcome for vulnerabilities that affect the confidentiality, integrity or availability of the public application, its deployment pipeline, research artifacts or machine-readable authority surfaces.

Examples include exploitable injection, authentication or authorization bypass where applicable, cross-site scripting, sensitive data exposure, supply-chain compromise, unsafe redirects, CSP bypasses with material impact, or integrity failures in published research artifacts.

Content disagreements, SEO observations, ranking changes, editorial corrections and claims about third-party platforms are not security vulnerabilities. Those should be handled as editorial issues, not vulnerability reports.

## Reporting

Use the contact published in:

`https://openai-ads.volponi.tech/.well-known/security.txt`

Please do **not** open a public GitHub issue with exploit details for an unpatched vulnerability.

Include enough information to reproduce the issue safely: affected URL or component, impact, reproduction steps, and any relevant request/response details with secrets or personal data removed.

## Handling principles

- Reports are evaluated against the current production application and repository state.
- No bounty or payment is implied by this policy.
- Good-faith testing should avoid destructive actions, persistence, denial of service, credential attacks, social engineering, or access to data that does not belong to the reporter.
- This project is independent and is not affiliated with, sponsored by, endorsed by, certified by, operated by, or maintained by OpenAI.
